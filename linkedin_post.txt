Deep Learning Project — Olive Leaf Disease Detection

I am pleased to share a Computer Vision project I recently developed and enhanced, focused on the automatic detection of Olive Peacock Spot disease (Spilocaea oleagina) on olive leaves using Deep Learning techniques.

Objective

The system classifies olive leaves into two categories:
- Healthy
- Infected (Peacock Spot / Oeil de Paon)

Approach and Models

Two models were developed and compared:
- Model 1: A Convolutional Neural Network (CNN) built from scratch, achieving approximately 85% accuracy.
- Model 2: Transfer Learning using MobileNetV2 as a base model, achieving approximately 95% accuracy.

Both models incorporate image preprocessing, normalization, and an adaptive confidence threshold to improve prediction reliability.

Key Features Developed

1. Web Interface (Flask)
A complete web application allowing users to upload leaf images via drag and drop, select between the two models, visualize the prediction result with an animated confidence gauge, and consult a real-time session history.

2. Real-Time Detection via Webcam
An enhanced OpenCV-based interface displaying a visual heads-up display (HUD) with a color-coded confidence bar, frames-per-second counter, detection frame guide, and screenshot capture functionality.

3. Batch Prediction Script
A command-line tool capable of processing an entire folder of images and exporting the results to a CSV file for further analysis.

4. Evaluation and Reporting Script
An automated evaluation script that benchmarks both models on a test dataset, generates a detailed summary report, and produces a visual montage of predictions.

Technologies Used

Python, TensorFlow, Keras, MobileNetV2, OpenCV, Flask, NumPy, Matplotlib, scikit-learn

Planned Improvements

- Addition of a "no leaf detected" class for improved robustness
- Integration of an object detection step prior to classification
- Cloud deployment via Docker and a REST API
